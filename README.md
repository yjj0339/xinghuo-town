> **线上地址：https://yjj0339.github.io/xinghuo-town/** （手机扫码即玩，自动存档）

## 🕹️ 操作

- **电脑**：WASD 移动 · J/空格攻击 · E 互动 · F 钓鱼 · H 回城 · B/I/C/Q/M 面板 · 滚轮缩放
- **手机**：左摇杆移动 · ⚔️ 按住连击 · ✋ 互动（有目标时按钮发光）

## 🛠️ 技术

- 纯原生 ES Modules；等距投影 + 深度排序 + 预渲染地形缓存管线
- **美术 = AI 生图管线**：102 张高清卡通资产（绿幕生成 → 自适应抠图 → 边缘去绿），零图片素材框架
