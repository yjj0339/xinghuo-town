# 🔥 星火小镇：荒谷拓荒记

> **线上地址：https://yjj0339.github.io/xinghuo-town/** （手机扫码即玩，自动存档）

一款 **2.5D 等距视角 · 开放世界 · 生存 × 经营 × 打怪** 网页游戏。纯前端零依赖，Canvas 2D 程序化矢量美术，明亮卡通风。

你是一位拓荒者，在这片怪物横行的荒谷中点燃第一堆篝火，把它建成一座繁荣的传奇小镇。

| 系统 | 内容 |

## 🕹️ 操作

- **电脑**：WASD/方向键移动 · J/空格攻击 · E 互动/采集 · F 钓鱼收杆 · 1-8 快捷栏 · B 建造 · I 背包 · M 地图 · 滚轮缩放
- **手机**：左侧摇杆移动 · ⚔️ 按住连击 · ✋ 互动采集 · 右侧菜单列打开各面板
- **新手路线**：跟着左上角主线任务走即可——篝火 → 工具 → 工作台 → 围墙 → 农田 → 招募 → 防御塔 → 哥布林王 → 繁荣小镇 → 三大 Boss → 远古祭坛终局

## 🛠️ 技术

- 纯原生 ES Modules，无构建、无依赖、无框架；等距投影 + 深度排序渲染管线
- 全部美术为 Canvas 2D 程序化矢量绘制（建筑/怪物/角色/物品图标共 100+ 种）
- 昼夜光照（径向渐变挖洞合成）、天气粒子、WebAudio 合成音效 25 种
- 种子化世界生成（分形噪声 + 纬度气候带 + 稀有生态区保底）
- `node tools/verify.mjs`：618 项无头断言（数据完整性/世界生成/全玩法链路/存档回路）
